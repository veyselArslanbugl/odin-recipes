# Odin Recipes

This project is a simple recipe website built as part of The Odin Project curriculum.

The website contains several simple recipes, each with its own page. The main goal of this project is to practice the fundamentals of HTML and learn how to structure a basic website.

By completing this project, I demonstrate my ability to:

- Create and structure HTML documents
- Use headings, paragraphs, lists, and links
- Add images with appropriate `alt` text
- Link multiple pages together
- Organize files and directories
- Use Git and GitHub to track and manage changes
